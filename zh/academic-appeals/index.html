Case map

先看案件類型，再決定申訴路線。

不是每一個不滿意結果都值得申訴。OTC 先看程序錯誤、證據缺口、不可抗力、溝通紀錄和學校規章。

01成績複核 / Mark Review

核對 rubric、feedback、分數邏輯、moderation 與是否存在明顯程序或評分錯誤。

02學術誠信 / Misconduct

處理 plagiarism、AI use、collusion、引用錯誤、聽證會陳述與補充證據。

03停學退學 / Progression

針對 failed module、attendance、visa risk、progression block 和 re-sit decision 做路線評估。

04特殊情況 / Mitigating Circumstances

整理醫療、家庭、心理、住宿、事故與不可抗力證據，避免只寫情緒化申訴信。

香港與亞洲 Deskcourse committee、appeal board、bilingual evidence

STEM / Lab / Project Desk實驗、代碼、project evidence

文件與文案 Deskappeal letter、timeline、evidence index

Six-stage workflow

6 階段服務流程。

每一步都保留文件版本與決策紀錄，避免臨近 deadline 時才發現缺證據。

Transparent package

3 種方案與返款承諾。

價格僅作公開參考；正式報價按案件急迫程度、文件量、聽證會需求與學校制度確認。

Consult諮詢級¥2K-5K

初評、規章核對、方向建議與簡版 evidence checklist。

Companion陪伴級¥8K-15K

證據包、申訴文案、多輪修改、提交前 review 與進度跟進。

Hearing聽證 / 訴訟級¥20K+

聽證會模擬、複雜證據、外部投訴或律師轉介協作。

承諾邊界 符合條款的成功案件返款 20%；未達預設結果且符合服務條款的案件返款 50%。不承諾學校必然改判，不代寫虛假材料。
