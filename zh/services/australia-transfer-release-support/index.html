澳洲轉校與 Release 申請協調

學籍核對 · 文件整理 · 兩校聯絡

按你的課程組合及學籍狀態，整理轉校申請材料與兩校時間表。

初步評估先說院校、專業及入學期限選擇指南語言與主課的限制怎樣核對服務與費用來訊了解需求，正式服務先報價準備資料五項背景，未確定可留空
轉校服務按階段跟進

先確認校方規則，再確認任務、負責人和截止日。

適合哪些情況

完成語言班後想換院校或專業；新校已發 offer，但原校釋放未明；已提出 release 申請卻不清楚缺甚麼；或兩校的文件及開學期限相互衝突。

先整理學籍與時間線

把語言、主課及課程組合列清楚，記錄原校學籍、CoE 狀態、新校 offer 條件及截止日。交付一份事項表，分清已確認、待校方確認及下一步。

準備申請理由與文件

依原校政策整理材料清單、課程對比和支持證據，協助修改申請陳述及電郵。理由須來自學生真實情況，學生核對內容後才提交。

兩校電郵與結果跟進

取得明確授權後，按約定向原校跟進程序及材料，向新校確認補件和入學期限。若收到拒絕通知，可協助整理理由、申訴資訊及可補文件；正式法律申訴或移民意見需另由合資格人士處理。

免費、服務費與第三方費用

初步需求了解：可先免費來訊說明基本情況，確認我們能協助甚麼；不包括完整文件審查、陳述撰寫或持續代聯絡。

正式協調服務：開始前書面確認涉及的院校、文件、修改次數、跟進期間、聯絡方式、費用及取消安排。尚未完成評估前不報統一價格，也不承諾整套服務免費。

第三方費用：學校收費、考試、認證翻譯及合資格專業服務等，按實際需要另行確認。校方批准 release 本身不得收費，與原課程退費及 OTC 服務費是不同事項。

工作流程與服務界限

① 提供基本背景。
② 核對原校政策與兩校時間表。
③ 確認服務內容及報價。
④ 整理材料，由你確認。
⑤ 按授權提交或協助你提交，跟進書面答覆。
⑥ 交回文件、結果及未完成事項。

OTC 提供教育申請材料和學校溝通支援，不代表原校或新校作決定，不保證釋放、退費、錄取或簽證結果。簽證及法律事項需另行處理。

怎樣開始

請提供原／新院校與專業、語言是否打包主課、主課是否開讀、原 CoE 狀態及新校 offer／開學期限。未確認可留空。

初次不用傳證件或完整 CoE；需要文件時先確認用途和傳送方式。已在 Threads 聯絡，可沿原對話補充；也可用右方 Email 或 WhatsApp。
