學歷認證與補件協調

WES 文件驗證 · 院校重送 · 截止日應急

文件被拒，不一定代表學歷被否定。先找出是文件內容、寄送方式、寄件權限還是驗證渠道出現問題，再按書面要求處理。

OTC 文件協調台不是替客戶「追一封電郵」

每宗案件建立文件清單、證據時間線、責任人、截止日及書面回覆紀錄。

適合哪些情況

WES 或同類第三方學歷評估顯示文件未收到、被拒、無法驗證或要求補件；原校表示已寄出，但評估機構仍不接受；申請院校截止日將至，需要同步查詢可否先審、後補或短期延期；或申請人需要把多所原校、多個評估項目及多所收件院校整理成可執行的跟進表。

本服務不會重新評定學歷，不替代發證院校、WES 或收件院校的審查，也不代替受監管的法律或移民意見。

先判斷退件屬於哪一類

傳送渠道：文件沒有經該筆學歷 Required Documents 指定的平台、認可電郵或密封寄送方式發出。
寄件權限：寄件人未能被核實為教務處、註冊組、考試或學術紀錄承辦人。
文件狀態：PDF 不能驗證、設有密碼／期限、缺頁、資料不一致或翻譯不符合要求。
案件匹配：WES reference number、姓名、學歷或收件人資料未能正確對應。
等待處理：文件已到達，但尚未完成收件、索引或驗證。

官方要求會因就讀國家、院校及學歷而不同；必須以客戶帳戶內該筆學歷的 Required Documents 和最新書面通知為準。

開始前一次提供的資料

① WES reference number 或其他案件編號（初步評估可遮住中間數字）；② evaluation 類型；③ 拒件／補件通知完整截圖；④ Required Documents 頁面；⑤ 被拒的院校、學歷和文件；⑥ 原校寄件部門、方式、日期及證明；⑦ 目標院校、課程、Applicant ID 和截止日；⑧ 可聯絡的原校教務／註冊部門。

初次諮詢不需要護照、身份證、住址、銀行資料或帳戶密碼。需要查看帳戶時，客戶本人登入並透過共享畫面確認；OTC 不要求客戶交出 WES 或院校帳戶密碼。

八步協調流程

① 確認目的、機構、文件及最早截止日。
② 核對官方 Required Documents 和拒件通知。
③ 建立文件、寄送與回覆時間線。
④ 形成「已確認／待確認／立即行動／風險」診斷表。
⑤ 向評估機構提交具體問題，確認可接受的重送方式。
⑥ 向原校教務或註冊部門提供重送清單與郵件草稿。
⑦ 向目標院校查詢先審、後補或延期安排。
⑧ 保存回覆、更新進度表，直至約定服務期完結。

客戶授權 OTC 對外聯絡前，會先確認收件人、必要資料和郵件內容。涉及客戶本人聲明、帳戶提交或個人承諾時，優先由客戶本人發出並抄送 OTC。

服務報價

免費範圍確認：判斷是否屬本服務、資料是否足以開始，以及是否需要立即尋求其他專業人士。

基礎診斷 £80–£120：核對現有文件、拒件原因、官方要求及截止日，交付一份書面處理方案。資料齊全後，通常以一個工作日完成首版為目標；實際時間在接受委託前確認。

完整協調 £280–£450：包括一個評估機構、一所原就讀院校、最多三所收件院校及十四日進度管理；包括郵件草稿、提交／寄送核對、回覆整理及進度表。

額外收件院校每所 £30–£50：按問題複雜程度及所需跟進輪次書面確認。超出上述機構數量、服務期、翻譯或緊急工作，另行報價。

第三方費用另計：WES、院校、翻譯、公證、認證、快遞、文件申請及其他第三方費用，須由客戶事先確認並直接或按書面約定支付。

客戶會收到甚麼

案件診斷表；文件與寄送清單；評估機構查詢草稿；原校重送說明；收件院校截止日期應急聯絡表；回覆及證據時間線；十四日內的進度更新紀錄（完整協調方案）。

所有對外文字都區分已知事實、客戶陳述、待確認事項與請求，不把「已寄出」寫成「已被接受」，也不把等待審核寫成認證成功。

標準委託協議摘要

委託雙方：客戶與 Overseas Tutorial Centre Ltd（OTC）。個案確認書列明服務、費用、開始日、服務期及聯絡人。

服務權限：OTC 只在客戶書面授權的範圍內整理資料、擬稿、聯絡和跟進；不索取帳戶密碼，不冒充客戶，不代表第三方作決定。

客戶責任：客戶須提供真實、完整、可核實的資料，及時核對草稿並完成本人必須提交的步驟。因遲交、錯誤、隱瞞或第三方延誤產生的後果，不由 OTC 承擔。

資料與保密：只收集完成服務所需資料；按客戶授權向評估機構、發證院校、收件院校及必要供應商披露。客戶應先遮除與本案無關的身份、住址、財務和第三方資料。

費用與開始：正式工作在服務範圍、價格及付款安排書面確認後開始。已完成的診斷、草稿、聯絡或跟進工作不因第三方拒絕、逾期或不回覆而自動退款；尚未開始的可取消工作按個案確認書處理。

結果與時限：WES、原校及收件院校保留審核與決定權。OTC 不保證文件獲接受、認證結果、院校延期、錄取或固定完成日期。

暫停與終止：資料不真實、客戶要求作出誤導陳述、欠款、無法取得必要授權或繼續工作可能違反第三方規則時，OTC 可暫停或終止服務並說明已完成工作。

確認方式：客戶以簽署確認書、確認電郵或其他可保存的書面方式接受個案範圍、費用及本摘要後，委託成立。個案確認書如與本摘要不同，以雙方最新書面確認為準。

重要服務邊界

OTC 提供教育行政、文件整理與溝通協調，不是 WES、院校或政府機構。涉及法律、移民、受監管職業資格或正式申訴權利時，會建議客戶尋求相應司法管轄區的合資格專業人士。

本頁報價是標準範圍；收到資料後才會發出個案確認書。任何服務開始前，客戶都會看到實際工作、交付、費用、第三方支出及取消安排。
