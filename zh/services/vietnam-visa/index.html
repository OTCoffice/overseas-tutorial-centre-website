越南簽證代辦

海外督導 Overseas Tutorial Centre（OTC）提供越南簽證代辦服務，從出行需求、文件準備到申請協調及進度跟進，協助你把每一步安排清楚。

電郵諮詢WhatsApp 諮詢

我們協助哪些事項？

  1. 確認需求：了解護照國家／地區、入境目的、停留日期與入境次數，核對適合的申請方向。
  2. 文件檢查：按個案提供清單，協助檢查申請資料、照片及行程資訊是否一致。
  3. 申請協調：在你確認服務範圍、報價與授權後，協助辦理及需要的承辦對接。
  4. 進度跟進：協助查看申請狀態、傳達補件要求，取得結果後提醒核對姓名、護照號碼、效期及入境次數。

旅遊及商務需求請分別說明；工作、就業、長期居留或其他特殊用途另作評估，服務範圍以書面確認為準。

費用清楚列明

項目說明
官方電子簽證費單次入境 US$25；多次入境 US$50。
OTC 代辦服務費按人數、需求與資料情況另行書面報價。
其他費用如涉及加急協調、翻譯或額外服務，先說明可行性、費用及條件，經確認後安排。

官方電子簽證最長可達90天，單次或多次入境；實際效期以核發結果為準。以上官方資料於2026年9月14日核對，申請時以越南官方電子簽證平台最新公布為準。代辦服務費不包含在官方費用內；官方及服務費的取消／退款條件將分開說明。

辦理流程

提交基本需求 → 核對申請方向 → 確認書面報價及服務條款 → 提交文件與授權 → 申請及補件跟進 → 核對結果。

若已自行申請，請先說明提交日期、目前狀態及是否收到補件通知，方便評估後續協助。出發時間較近的個案，請先提供確切日期；能否承接及處理時間需確認，不承諾固定日期出簽或保證獲批。

常見問題

一定要透過代辦嗎？

你也可以使用越南官方平台自行申請。OTC 提供的是文件與流程協助，適合希望由專人協調或需要中文溝通的申請人。

是否適用免費留學代辦？

越南簽證代辦是獨立服務，費用按書面報價確認，不等同免費留學申請代辦。

可以保證簽證或入境嗎？

OTC 並非簽證核發機關。簽證結果及入境決定由相關主管機關作出；我們提供申請協助及進度跟進。

第一次諮詢要傳護照嗎？

先提供右列基本需求即可，不需在公開留言或初次諮詢傳證件照片。確認承接後，再按清單與指定方式提供必要文件。

官方資料

越南國家電子簽證系統 · 越南出入境管理局

諮詢前準備

  • 護照國家／地區及目前所在地
  • 預計入境與離境日期
  • 申請人數
  • 旅遊、商務或其他用途
  • 單次或多次進出
  • 預計入境機場／口岸
  • 是否已提交申請

不用公開證件號碼或護照照片。
