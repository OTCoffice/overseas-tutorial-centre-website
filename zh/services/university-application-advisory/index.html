各國院校名錄與認可查詢

已整理的院校專頁 →

院校範圍以各國主管機關、認可機構或官方留學平台為依據。不同來源的機構類型及收錄範圍不同，請先看說明，再進入國別名單。

英國院校名單 →

GOV.UK 學位認可與四地院校登記 ↗

按英格蘭、蘇格蘭、威爾斯及北愛爾蘭分別查核；授課機構與學位頒授機構分開。

澳洲院校名單 →

TEQSA National Register ↗

全國註冊高教機構，按 Australian University、University College 等類別查詢；國際生課程另核對 CRICOS。

紐西蘭院校名單 →

NZQA 教育機構查詢 ↗

高教機構與資格查核；八所大學另參考 Universities New Zealand，不能把理工與私立機構排除。

美國院校名單 →

NCES College Navigator ↗

按州別、學歷層級及機構類型搜尋；資料庫收錄範圍以 NCES 說明為準，專業認可另查。

加拿大院校名單 →

CICIC 加拿大教育機構名錄 ↗

按省及地區查詢教育機構認可狀態；留學簽證及畢業後工作資格另核對 IRCC。

愛爾蘭院校名單 →

HEA 高教機構名錄 ↗

依法與 HEA 合作或獲核心公共資助的機構；不是所有私立高教院校名單，私立課程另查 QQI。

日本院校名單 →

JASSO 學校搜尋 ↗

可按學校類型、地區等查詢；本搜尋收錄的學校資料不等於文部科學省全部大學總數。

韓國院校名單 →

Study in Korea 院校查詢 ↗

韓國政府留學平台；院校、學歷層級與國際生招生資料依搜尋條件查詢。

香港院校名單 →

教育局學位頒授院校名錄 ↗

22 所可頒授學位的高等教育院校，含公帑及自資；副學位及非本地課程另查。

新加坡院校名單 →

MOE 自治大學名錄 ↗

六所自治大學；不等於全部可讀學位的機構，藝術大學與私立教育機構分開核對。

台灣院校名單 →

教育部大專校院一覽表 ↗

按學年度列出公私立、一般大學與技專校院等；國際生、港澳生與僑生的招生渠道分開。

馬來西亞院校名單 →

MQA Malaysian Qualifications Register ↗

按公私立機構及認可課程查詢；院校登記與課程認可不是同一項。

泰國院校名單 →

MHESI 認可高教機構名單 ↗

主管機關公布的認可院校文件；按文件日期及機構類型查核。

德國院校名單 →

HRK Hochschulkompass ↗

德國大學校長聯席會議院校資料庫；按大學、應用科技大學及藝術音樂院校等類型查詢。

法國院校名單 →

Campus France 課程與院校目錄 ↗

按 Licence、Master 等學歷查課程及提供院校；不把標章或某申請系統會員名單當全部認可院校。

荷蘭院校名單 →

Nuffic / Study in NL 院校分類 ↗

研究型大學、應用科技大學及國際教育機構分開；課程認可需另核對。

意大利院校名單 →

Universitaly 院校搜尋 ↗

義大利官方高教入口，按大學及 AFAM 等類別查詢；各學歷課程另有招生要求。

瑞典院校名單 →

Universityadmissions.se 院校名錄 ↗

招生平台院校聯絡名單，含 universities 與 university colleges；各校授予博士學位權不一。

芬蘭院校名單 →

Study in Finland 院校目錄 ↗

大學與應用科技大學分列，按官方平台當期名單查詢；其他特殊主管機構另查。

丹麥院校名單 →

丹麥高教機構認可資料庫 ↗

可查當前及歷史機構，須留意狀態；不把歷史或已合併機構當現行院校。

挪威院校名單 →

Study in Norway 高教機構名錄 ↗

按大學、專門大學、大學學院及有認可課程的機構分類；認可狀態另依 NOKUT。

冰島院校名單 →

冰島政府大學名錄 ↗

政府列出七所大學層級機構；不同院校提供的學歷及授課語言不一。

希臘院校名單 →

Study in Greece 院校搜尋 ↗

留學平台所列院校及課程，不把平台參與院校數當全國機構總數。

奧地利院校名單 →

OeAD 高教機構名錄 ↗

公立大學、私立大學、應用科技大學及師範高教機構分開查詢。

巴西院校名單 →

MEC 官方高教機構與課程登記 ↗

由教育部說明並連到 e-MEC，查機構及課程授權狀態；不只列研究型大學。

智利院校名單 →

Mi Futuro 高教機構搜尋 ↗

政府服務頁連到 Mi Futuro，查大學、專業學院及技術培訓中心，機構類型分開。

南非院校名單 →

DHET 高教院校及私立機構登記 ↗

公立大學與註冊私立高教機構分開；私立機構須依當期登記冊核對。

埃及院校名單 →

政府公布認可高教機構名單 ↗

公立、私立、非營利及其他機構依官方類別查閱，招生與課程認可另外確認。

  1. 了解背景確認學歷、成績、專業、入學時間與預算。
  2. 比較課程核對入學條件、學制、費用與申請日期。

常見問題

名單上的學校都能代辦嗎？

這是選校資料目錄，收錄不表示校方授權或合作關係。招生部會先確認院校接受的申請渠道，再說明可代辦範圍；自行申請的學校也可安排獨立諮詢。

沒有語言成績，可以開始準備嗎？

可以先比較課程、整理學歷與申請時間。是否接受後補成績、條件錄取或語言課程，要按該校當年度課程規定確認。

目錄沒有想申請的學校怎麼辦？

直接發學校名稱或課程連結，招生部可另外查詢。目錄是已整理的院校，並非各國全部大學。

可以同時比較不同國家嗎？

可以。先確認專業與全年預算，再比較學制、學費、生活費、授課語言和申請時間。畢業後工作及居留要求另按當期官方規定評估。

大學申請諮詢

告訴招生部你的學歷、目標專業、入學年份、成績與預算，安排選校及申請。已有心儀課程，可直接附上課程連結。
