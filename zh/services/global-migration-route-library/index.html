申請前核對

逐項核對護照國籍、學歷及語言、資金與收入、雇主或學校資格、家屬條件、居留續簽、永居計算與官方最新生效日期。特別注意：網路整理的政策可能包含提案、尚未生效規則或過時數字，不能直接作為簽證申請依據。

OTC 可以協助甚麼？

提供免費初步路線篩選、留學及課程銜接規劃、文件清單整理與官方來源核對；涉及移民法律、稅務或受監管意見時，轉介具相應資格的專業人士。
