OTC ISEE 原創入門練習 · 試編第 1 單元

非官方題；示範用途，尚非按級別校準的完整模擬卷。

Verbal Reasoning

1. RELUCTANT most nearly means: A eager / B unwilling / C noisy / D accurate

2. Although the trail was steep, the hikers remained ___ and reached the summit. A determined / B indifferent / C confused / D absent

Quantitative Reasoning

3. If 3x + 7 = 22, what is x? A 3 / B 5 / C 7 / D 9

Reading Comprehension

Passage: “After the community planted trees along the street, residents noticed more shade during summer afternoons. The project also encouraged neighbors to meet regularly to care for the young trees.”

4. Which benefit is NOT directly stated? A More shade / B Neighbor cooperation / C Lower electricity bills / D Regular tree care

答案與解析

  1. B。Reluctant 指不情願的。
  2. A。Although 表示轉折；儘管困難仍完成，應選 determined。
  3. B。3x = 15，因此 x = 5。
  4. C。文中沒有提到電費下降，不可自行推論為直接陳述。
