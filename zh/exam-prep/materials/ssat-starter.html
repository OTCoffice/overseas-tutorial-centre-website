OTC SSAT 原創入門練習 · 試編第 1 單元

非官方題；示範用途，尚非按級別校準的完整模擬卷。

Verbal

1. LUCID most nearly means: A obscure / B clear / C fragile / D sudden

2. SEED is to TREE as EGG is to: A nest / B bird / C shell / D feather

Quantitative

3. A jacket costs $80 before a 25% discount. What is its sale price? A $20 / B $55 / C $60 / D $75

Reading

Passage: “The town library began opening an hour earlier. At first, few people arrived before nine, but within a month students had begun using the quiet space to study before school.”

4. What changed over the month? A The library closed / B Students increasingly visited early / C School started later / D The library moved

答案與解析

  1. B。Lucid = clear，清晰的。
  2. B。種子可長成樹，蛋可孵化為鳥；關係是發展為。
  3. C。80 × (1 − 0.25) = 60。
  4. B。文中明確指出學生開始在上學前使用圖書館。
