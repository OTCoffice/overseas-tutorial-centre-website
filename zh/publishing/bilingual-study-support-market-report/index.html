雙語教輔市場調查

面向中國國際學校、國際部、雙語學校與 pathway learners，建立 BTEC Level 3、A-Level、IB、Foundation 與 BTEC Higher Nationals 的獨立雙語學習支持產品線。

English version返回中文首頁
核心判斷

Level 3 是出版入口；Level 4/5 是中心交付與進階路線。

OTC 應把 BTEC Level 3 視為核心雙語教輔方向。對海外書局而言，BTEC Level 3 / International Level 3 正好對接中國國際學校、國際部和 pathway learners 的升本需求，是最適合先做雙語輸出系統出版的入口。BTEC Higher Nationals Level 4 / 5 HNC-HND 則應繼續作為 OTC 申請 Pearson centre、online delivery 和 LMS 建設的中長線。

01BTEC Level 3assignment brief 解讀、criteria awareness、evidence planning、Pass / Merit / Distinction 目標意識與雙語學習伴侶。
02A-Level / IAL商科、經濟、會計、心理等科目的 command words、evaluation、case application 和英文論述訓練。
03IBDPTOK、EE、IA、Business Management 等 rubric 解讀、研究問題和學術寫作支持。
04Foundation / Pathway學術寫作、referencing、business vocabulary、assignment-based study support。
05BTEC Higher NationalsLevel 4 / 5 HNC-HND 的 unit outcomes、report writing、top-up progression 和未來中心交付支持。
06Apps & ISBN詞彙測試、writing-frame trainer、ISBN-controlled PDF guide 與 Payhip / KDP / app bundle。
市場缺口

學生需要一套雙語輸出系統。

官方 specification、教材和 assessment rules 仍然是基礎。中國 EAL 學生真正卡住的地方，是如何把已經理解的學科內容轉換成合規、清楚、有證據的英文學術輸出。OTC 的定位是出版能支持理解、詞彙、規劃、evidence discipline 與 academic integrity 的獨立雙語學習資源。

概念理解中文概念到英文學科語言

用雙語概念圖、key-term explanation 和 course-linked glossary 降低閱讀門檻。

評核語言Command words and criteria

把 describe、explain、analyse、evaluate 等評核動詞轉換為學生能操作的寫作任務。

作業規劃Brief to evidence plan

幫學生讀懂 assignment brief、拆解任務、建立 evidence table 和進度清單。

英文寫作Paragraph and report structure

使用 PEEAL 類寫作框架、evaluation language、Harvard referencing 和 feedback literacy。

升學理解Progression clarity

解釋 Level 3 to undergraduate progression、Higher Nationals、foundation、top-up 等路線。

合規邊界Independent support only

以獨立學習支持語言呈現，清楚標示官方文件、centre guidance、可提交成文與保分承諾的邊界。

產品路線

第一批產品應按市場痛點排序，而不是按資格名氣排序。

BTEC Level 3 Business Assignment Writing Toolkit

最優先。面向中國國際課程學生，處理 assignment brief、criteria、evidence planning 和 academic phrasing。

HN route
書號分配

ISBN 只給進入正式出版流程的產品。

  • 一本正式銷售書對應一個 ISBN。
  • PDF ebook、POD paperback、EPUB / Kindle 應按不同格式分開管理。
  • app 和 browser tool 通常不需要 ISBN，除非與正式 ebook / PDF publication 捆綁銷售。
  • 草稿、preview、tutor note、sample chapter 只使用內部 ID。
合規措辭

對外只使用獨立學習支持語言。

  • 可用：Independent Study Companion、Bilingual Study Support Toolkit、Assignment Planning Companion。
  • 避免：Official Guide、Model Answers、Marking Guide、Guaranteed Pass、Examiner Secrets。
  • 未取得書面授權時，不暗示 Pearson、Cambridge、IB、College Board 或任何 awarding body 背書。
  • 每個產品頁保留 academic integrity 和 independent resource 邊界。
