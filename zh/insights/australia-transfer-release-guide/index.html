澳洲轉校需要 Release 嗎？語言班、主課與申請材料怎樣核對

語言班讀完、雅思達標，未必代表轉校手續已完成。先核對課程組合與學籍，再整理理由、證據及兩校日期。

作者：《海外留學導報》編輯部｜海外督導 OTC 閱讀時間約 8 分鐘 適合讀者：學生、家長、升學顧問

Release 是院校轉學程序的一部分。

先確認需要甚麼，再談申請理由

Release 是院校轉學程序的一部分。收到新校 offer、雅思達標、原校退學、取得釋放及新校正式入學，是不同事項，應分別取得書面確認。尚未看到課程組合及學籍記錄時，不能直接說一定需要釋放，也不能預測一定被拒。

語言班結束，不等於主課完成六個月

導報提示

教育部說明：一般轉校限制以主課完成六個日曆月為界，從主課開始計算。學生簽證涵蓋多個課程時，主課通常是最後的主要課程；主課前的語言等課程也可能處於限制期間。學校教育階段有不同計算規則，不能套用成人語言加學位的例子。

所以首先列出：語言班及學位的院校、是否打包、各課程開始和結束日期、主課是否真正開讀，以及目前 CoE 與學籍狀態。回國或完成語言班，不能單憑這一件事判定限制消失。

所謂「釋放信」，重點是校方記錄

實務重點

教育部 PRISMS FAQ 說明，自2018年起，相關釋放由原院校記錄於 PRISMS，並非一定要學生取得一封實體信。可以請原校確認結果與生效時間，再請新校確認接下來可辦理的入學程序。OTC 不替院校操作這個系統。

申請材料：把理由與證據對起來

按原校現行政策確認表格、有效的新校入學 offer、支持材料及預計處理時間。ASQA 指引要求院校有書面評估程序；課程組合涉及多個提供者時，受轉校影響的提供者須按自身政策評估。

整理一張材料表：第一欄寫轉校理由，第二欄放相應證據，第三欄說明仍待確認之處。雅思可以證明語言能力，不能單獨證明原課程不合適；新校名氣較大也不能代替具體的學習理由。

材料示例：從「想換專業」寫到具體差異

以下是假設示例，不是獲批案例：一名學生希望從一般商科改讀資訊系統。可先對比兩個課程的必修、選修、先修要求及學習成果，再用自己真實的學習經驗說明為何調整方向。

例如，若新課程確有與其目標相關的資料庫及系統分析內容，可引用官方課程頁，並說明本人如何發現這個興趣。也應查清原校是否已有相關方向或轉專業安排，以及曾得到甚麼答覆。不能在未查證時寫「原校完全沒有相關課程」。

最後把新校 offer 條件、所需英語證明及開學時間放在同一份說明中。這樣是讓校方容易核實理由，不代表符合任何院校的必批條件。不要虛構疾病、家庭困難、誤導銷售或其他特殊情況。

若被拒絕，先讀書面理由

ASQA 指引要求院校書面說明拒絕理由及申訴權利。應保存通知，記下適用期限和提交渠道，逐項分清是缺少文件、事實爭議，還是不符合原校政策，再决定可補甚麼。

同時向新校查詢能否延後入學及 offer 是否需更新。沒有書面答覆前，不把延期當作已批准；不要只等原校回覆而錯過另一邊的截止日。

費用、退費與簽證分開確認

ASQA 說明院校不得就批准釋放收費；但這不等於原課程一定全額退費，也不代表翻譯、顧問或其他服務免費。退費應另查原協議及適用規則。

Release 不是簽證批准。新課程、學籍變更及返澳安排是否涉及簽證問題，應向澳洲內政部或合資格移民專業人士核對。本文提供一般教育程序資訊，不能據此自行判斷簽證仍有效或可以返澳。

海外督導可以怎樣協助

我們可協助整理課程與學籍時間線、核對校方文件清單、修改基於真實事實的申請說明，以及在取得授權後跟進兩校電郵。正式決定由院校作出。
