免費代辦與服務範圍

先免費比較國家、學校、課程及預算。確認適用的合作項目後，OTC 語校申請代辦及簽證材料協助免收服務費；目錄收錄不代表每所學校均已與 OTC 合作。委託前會說明適用範圍，其他付費服務另行報價。

  • 選校與選課：按程度、目標、年齡及時間比較校區、課表、入學條件與住宿。
  • 費用核對：取得校方書面報價，整理已含、另付、付款日期及取消退款條款。
  • 申請與入學：協助整理文件、核對報名內容、遞交申請及跟進校方回覆。
  • 簽證與行前：按國籍及居住地核對官方要求，整理材料清單、住宿、報到及接機資訊。
  • 到校聯絡：遇到課程或住宿問題，可協助向校方反映；調整與退款由校方按合約處理。

錄取、簽證、住宿名額及學習成效由相應條件決定；免費代辦不代表免學費、最低價或保證核准。

課程怎樣選

課程比較重點
一般語言入學程度、班級人數、每週實際授課小時、上午／下午課及分班方式。
密集與一對一團體課、一對一及自習各佔多少；每堂分鐘數與額外收費。
考試準備IELTS、Cambridge、日語等目標考試、起點要求、模擬考及考試費。
升學語言是否銜接指定院校、完成後仍需哪些成績與入學條件。
職場與專業語言面試、商務、簡報或專業內容是否列入課綱及適合現有程度。
青少年與親子最低年齡、監護、住宿、接送、活動、家長安排及假期開班日期。

成人班沒有全球統一的年齡上限；最低年齡、零基礎班及熟齡課程須逐校確認。未成年人應同時核對課程、住宿及監護安排。

完整費用清單

類別應列入報價或預算
OTC 服務適用合作項目的申請代辦與簽證材料協助：服務費 0 元；額外服務先另行確認。
學校費用學費、報名、教材、測驗／考試、旺季附加費及學員保障。
住宿住宿安排費、房租、押金、餐食、水電、洗衣、提前入住及假期延住。
政府及第三方簽證、居留／學習許可、簽證中心、翻譯、公證、保險、體檢及銀行匯款。
生活與交通機票、接機、當地交通、餐飲、通訊、個人支出與備用金。

總預算＝學校收費＋全程住宿＋生活交通＋政府及第三方費用＋備用金。財力證明是可供使用資金的證據，不是向政府繳交的學費，也不應不加區分地重複計入生活費。

比較報價時統一幣別、開課日期、週數、每週課時與房型。核對報價有效期、優惠條件、訂金與尾款、收款方、收據、退款期限及拒簽扣費；尚未確定的費用逐項列明。

申請資料與行前安排

  1. 初步諮詢：年齡、所持護照的國家／地區、現居地、程度、學習目標、出發年月、週數及總預算；不用在公開留言提供護照號碼。
  2. 學校申請：校方表格、護照資料、分班測驗及課程要求的學歷或語言證明。未成年人另確認家長同意與監護資料。
  3. 簽證／居留：按官方個人清單準備錄取及付款證明、財力與資金來源、保險、住宿等；各國所需文件及翻譯規則不同。
  4. 出發前：確認入境文件、住宿起止日、校方緊急聯絡人、報到地點、接機與入境後登記。

先確認受理資格與課程名額，再按校方和政府時程付款及申請。政府處理時間與住宿供應會變動，實際出發安排應保留餘裕。

申請流程

  1. 提供國家、學習目標、時間與預算。
  2. 比較課程、確認名額、完整報價及取消條款。
  3. 按校方程序協助準備及遞交申請。
  4. 確認入學，準備簽證材料與行前安排。
