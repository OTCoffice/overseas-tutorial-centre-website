加拿大

升學銜接

先選省份與 RN／實務護理等資格方向 → 核對省級認可課程 → 完成學業及該省註冊要求 → 求職 → 分別確認工作許可與移民資格。

加拿大

持證銜接

先選擬執業省份 → 向監管機構查海外資格評估渠道 → 完成學歷、語言及所需補修／考試 → 省級註冊 → 求職與簽證；不一概要求重讀加拿大學位。

加拿大

課程院校

護理學士、第二學位／加速課程及 Practical Nursing 的資格方向不同。以安大略省為例，RN 與 RPN 使用不同教育與考試要求；可先查 CNO 認可課程，其他省份另向當地監管機構查核。

加拿大
加拿大

入學要求

核對理科先修課、學歷等值、語言及臨床實習條件。院校接受國際生、課程專業認可與畢業工簽資格需分別查證；不能只看學校屬 DLI。

加拿大

語言要求

入學與省級註冊要求分開；英語或法語證據、接受的考試及豁免按目標省份。魁北克等地的法語要求及專業程序不可直接套用安省規則。

加拿大

護士註冊

加拿大按省／地區監管，沒有一張適用所有地區的統一護士牌照。安省 CNO 接受指定 ECA 機構資料，亦列有可接受的 NNAS expedited reports；不可把 NNAS 當作全加拿大必經的唯一步驟。CNO 申請須由申請人自行完成與提交。

加拿大

就業居留

工作許可與護士註冊分開。Express Entry 的醫療及社會服務類別仍需符合所屬移民項目、職業與工作經驗及該輪邀請條件；省提名亦有各省要求，不以護理畢業或職業在清單上保證獲邀。

移民類別
加拿大

申請材料

完整護理教育、理論與臨床課程、註冊及執業紀錄、語言證據和姓名一致的身分資料。確認由哪個 ECA／原機構直接送件；一般移民學歷評估不自動滿足護理監管要求。

加拿大

申請時程

按省份先完成資格與課程比較，再安排語言、驗證及補修。安省要求先收到符合規定的學歷評估資料才開始相應申請；各省審理與考試排期分別確認。

加拿大

申請流程

  1. 確認背景：是否持有護士資格、擬讀課程或直接認可。
  2. 核對條件：專業認可、學歷、語言、臨床及可用申請渠道。
  3. 準備文件：按院校、監管機構及本人／僱主權責送件。
  4. 分段跟進：錄取、註冊、聘用與居留各自核對結果。
加拿大

費用服務

海外督導雙語世界｜招生部協助比較課程、核對入學條件、準備材料及跟進院校；註冊申請由本人、指定僱主或主管機構按規則辦理。

項目安排
學費依課程、入學年度與學生身分查學費；列明一年／全程及後續調整。
生活實習住宿、保險、交通、實習通勤或異地住宿；依城市與校方要求列支。
資格考核語言考試、文件驗證、認證翻譯、註冊、所需補修／考核與簽證由相關機構收費，依適用程序查價。
申請服務非香港院校申請沿用免費代辦安排，按一級／二級代理及校方允許渠道確認；獨立諮詢與其他委託另議。
其他委託語言與學習輔導、註冊文件準備及求職協助按範圍另行報價；個別移民及專業資格意見由相應合資格人士處理。
