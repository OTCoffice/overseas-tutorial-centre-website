# 導報發布工作流程：本頁題圖與 X 分享預覽

生效：2026-09-15。適用於海外督導官網所有新導報及題圖更新。維護：導報編輯／網站發布人。

## 完成標準

一篇文章只有在「全文與來源已核查、正文顯示本頁題圖、分享標籤指向同一張圖、正式網址與圖片可被公開讀取、指定平台草稿實際顯示正確預覽」均有證據後，才能宣稱分享驗收通過。HTTP 200 和部署成功不能代替平台預覽驗收。

若平台沒有顯示卡片，記錄為「網站已發布；X 預覽待確認」，繼續排查或明確報告限制。不得把推測的快取原因寫成已證實原因，也不得要求使用者再遇到一次才補測。

## 1. 建立文章與本頁題圖

- 核查當期官方資料，正文、標題、日期、來源和 Notion 備份一致。
- 每篇必須有專屬題圖，內容與本篇主題一致，不使用官網 Logo 或其他文章圖片替代。
- 採用適合社群的大圖，預設 PNG／JPEG、1200 × 630；確認標題完整、縮小後仍可辨讀、沒有文字溢出或假照片。
- 使用現有導報排版生成文字題圖時，設定 `socialTitleZh`，避免長標題被截斷。
- 題圖檔名包含內容雜湊或獨立版本；更新圖片使用新檔名，保留舊檔供既有連結使用。不要只覆寫同名圖片後假設社群立即更新。
- 在文章 JSON 明確設定 `shareImageZh`、`socialImageVersion`、`socialImageWidth`、`socialImageHeight`。英文文章使用對應欄位及版面。
- 本頁正文必須真的渲染 `<figure>`／`<img>` 題圖，含正確 alt、寬高；僅有 OG 標籤不算「本頁有題圖」。

## 2. 檢查靜態分享標籤

- 原始 HTML 的 head 內須有唯一 canonical、og:url、og:title、og:description、og:image、og:image:type、width／height，以及 twitter:card、twitter:image、twitter:title／description。
- 使用 `summary_large_image`；圖片使用公開 HTTPS 絕對網址，不能依賴 JavaScript、登入、Cookie、暫存附件或私有儲存。
- `og:image`、`twitter:image` 與正文題圖必須為同一圖檔；查證實際檔案格式、尺寸、大小，不只相信標籤數字。
- 不得因圖片生成失敗而照常宣布發布完成；先修好依賴／圖檔再繼續。

## 3. 本地發布閘門

```bash
python3 scripts/check-herald-share.py content/ARTICLE.json
```

- 檢查桌面及手機：題圖完整、可讀；表格可捲動但正文不可裁切；分享按鈕帶本頁網址；延伸閱讀沒有自我連結。
- 保存本地檢查輸出及題圖截圖。核對生成器與文章來源，避免只修輸出 HTML，下一次生成又消失。
- 整站生成如改寫舊內容，只保留本次文章及必要索引變更；保留其他工作者的改動。

## 4. 部署及公開抓取

- 合併最新遠端版本，不強制推送；提交文章、題圖、來源及索引。
- 等待對應 commit 的正式部署成功，確認正式網域實際內容與預期一致。

```bash
python3 scripts/check-herald-share.py content/ARTICLE.json --live
```

- 使用一般讀取與 Twitterbot User-Agent，對文章及圖片實際 GET。檢查 HTTP 狀態、MIME、圖檔內容、robots.txt 及可能的防機器人攔截。
- 檢查導報索引、分類索引、搜尋、sitemap 和 canonical。保留 SHA、部署結果、測試時間及圖片網址。
- 模擬 User-Agent 只代表網站在這種請求下可讀，不能證明 X 的真實爬蟲已抓到。

## 5. X 草稿驗收（不可省略）

- 使用已登入 X 的發文框或分享按鈕，先確認沒有使用者尚未完成的草稿；保留原稿，不覆蓋。
- 將正式文章網址放入測試草稿，等待卡片載入；確認本篇題圖、標題、網域及點擊目的地，保存畫面證據。
- 測試不等於公開發文授權。沒有明確發文指示時，不按 Post；檢查後只清除本次建立的測試文字或留作使用者要求的草稿。
- 若沒有圖：核對卡片標籤、圖片 URL／格式、真實 GET、robots／WAF、重導向、部署時間；查閱 X 官方 Cards troubleshooting。一次有依據地測試新的分享查詢參數可協助辨識舊 URL 快取，canonical 仍維持原文章網址；不要反覆編造大量網址。
- 網站修正後重新驗收。平台快取、爬蟲時機或帳號介面差異若仍無法確定，要說明實際可見結果，不能聲稱「一定正常」。
- 如使用者要立即發出有圖貼文，可在取得／已有明確發文授權後，另附本篇題圖並保留文章連結；這是圖片貼文，不能假稱自動連結卡片已修復。舊貼文不一定立即更新，不能承諾回溯刷新。

## 6. Notion 與交付記錄

- 備份全文及來源，保存正式網址；Notion cover 使用同一張公開題圖。
- 發布紀錄包含：文章 URL、題圖 URL、commit／部署、網站閘門結果、桌面與手機結果、X 草稿「通過／待確認」及證據。
- 完成訊息分清「網站已上線」「本頁題圖已顯示」「X 草稿已看到正確卡片」。未測的項目不能寫已完成。
