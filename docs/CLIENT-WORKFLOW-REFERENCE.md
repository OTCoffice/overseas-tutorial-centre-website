## 參考範圍

已登入的小希顧問帳戶中，實際查看學生個案的八步流程、選校列表、申請材料、背景表、錄取結果、接受 offer／費用、簽證資料、簽證結果、境外服務。已查看「轉給學生填寫」彈窗：需要綁定學生手機，再經小程式填寫定校與申請資料、查看進度。未輸入手機、未發送邀請、未修改原學生資料，未複製任何學生記錄、附件或銀行帳戶。

本次實作對應上述可觀察結構，不宣稱已取得小希小程式全部頁面或後端。OTC 保留電郵驗證登入與穩定帳戶 ID 權限；沒有建立公開個案分享連結。

## 已實作

八步：留學方案、確認申請院校、提交申請資料、院校錄取結果、確認錄取與費用、提交簽證資料、簽證申請結果、境外服務。國家分類由個案、顧問公開項目及客戶已儲存意向整理。

11 組表格：個人資料、教育、考試、工作、留學意向、意向院校、緊急聯絡人、簽證背景、付款紀錄、境外服務、補充資料。重複組最多各 15 筆；沿用白名單、每欄 1,500 字、總量 50,000 字限制。

儲存草稿與提交 OTC 核對分開；提交驗證基本資料，記錄提交版本與時間，建立顧問審核待辦，不修改院校或簽證階段。提交後再修改會標示草稿尚待重新提交。客戶意向、付款自述與顧問核實結果分開保存。

材料依院校／簽證分類，支援多檔選擇及拖放；每次最多 30 份，每份 2 MB，每個案 100 份，沿用私人附件授權。未提供 AI 提取、電子簽署、代付款或院校／政府自動遞交功能。

顧問端可維護已公開項目的課程、校區、學制、語言搭配、錄取、條件及付款資料；個案編輯可維護對客簽證及境外安排。未公開的院校路線和內部資料不會出現在客戶 API。

- 個案八步中的簽證資料頁：英國代辦服務費 1,000 元／人次，政府申請費另付。
- FAQ 新西蘭學生簽證：500 元；澳洲自行申請或轉代理後學生簽證：500 元；澳洲家長監護陪讀簽證：1,000 元。
- 2026-10-15 的澳洲學生簽證回覆：從院校申請開始跟進、沒有拒簽等特殊情況免服務費；有拒簽史的個案服務費 AUD 1,100。

- 小希 FAQ「境外服務內容及收費標準」明言詳細內容與價格須發起諮詢後提供。因此住宿、學術、健康等未核實價格不能補寫數字，也不能把校方學費、政府費用或代理佣金冒作 OTC 服務費。

匯率來源 https://open.er-api.com/v6/latest/CNY，快照為 2026-11-17 00:02:31 UTC。CNY 1 = GBP 0.113567 / USD 0.149718 / TWD 4.930966 / HKD 1.17469 / AUD 0.222178 / EUR 0.136112。按原幣換算到兩位小數，AUD 原價先除以 CNY→AUD 匯率再換目標幣。NULL 保留報價，0 才表示免服務費。scripts/sync-otc-service-fx.py 可更新快照，更新後須審閱再部署。

## 驗收

16 項測試：身份／跨站寫入、個案隔離、公開投影、明確管理授權、完整表格白名單、重複組上限、提交基本欄位、提交版本、審核待辦去重、六幣換算及空價格與免費的差異。

本機虛構資料：八步均可切換；意向保存、完整背景提交、簽證欄位草稿保存；兩份虛構 TXT 按成績單類別批次上傳；六幣欄位與 RMB 1,000 換算核對；480 CSS px 窄幅頁面無正文水平溢出，費用表在容器內橫捲。

本機記憶體 API 不能證明正式 Neon 寫入、電郵或外部服務已運作。正式站應核對部署版本及登入後可見結構；沒有建立測試正式帳戶或寫入正式客戶記錄。社媒分享預覽未重新驗證，未宣稱已驗證。
