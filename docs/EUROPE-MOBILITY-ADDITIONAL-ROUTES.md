# OTC 歐洲移居新增候選路線（110條原RUN清單之外）

更新及官方檢查：2026-11-15。此處路線不修改原RUN 99+11=110條統計，不得冒稱已正式發佈或通過C/D。

## Czechia — long-term visa / residence for the purpose of doing business（經商／貿易執照／自僱）
- 建議新增 ID: `czechia-business-trade-licence`；狀態：**現行制度，部分官方欄位核實，C/D=false**。俗稱「Živno visa」不等於貿易執照本身即可合法居留。
- 申請人：第三國公民可依條件申請。中國大陸、香港特區、台灣三地護照逐領館申辦、預約及配額尚未確認。
- 資格：實際開展合法經商、持牌貿易、個體經營或符合法定條件的企業法定機關工作。長期簽證必須證明商業登記或貿易登記、住所、生活資金、無犯罪記錄等，批准前須依規購醫療保險。經商長期居留還需證明每月家庭收入、無欠款、保險等，需持續維持經商目的。
- 金額：領館初次長期經商簽證費CZK 5,000，捷克境內經商長期居留申請CZK 2,500；生活/家庭資金精確門檻依適用表及家庭人數待核。並不等於必須定額投資。
- 審核時間：長期經商簽證一般90日，複雜個案120日；境內長期經商居留一般60日，法定停時計算及例外適用。
- 期限：初次長期簽證最長1年，延簽累計最多1年；之後可依條件在境內申請最長2年的經商長期居留，後續續卡依規進行。
- 工作／經商：已核長期簽證准予從事相應合法經商活動；不得將此寫成自由受僱工作許可。其他就業權待核。
- 家屬：家屬團聚的具體申請資格、資金、工作權及居留期限未逐欄核實。
- 5年永居：捷克內政部確認一般符合5年**連續合資格臨時居留**可申永久居留，不是自動批准；一般90日以上簽證與長期居留年資可全額計入（有例外），普通離境須通常每次不超過6個月且總離境不超過310日，另有法定例外。具體個案另核其他必要條件。
- 容易混淆的「5年」：從其他長期居留**轉換經商目的**一般要求先在捷克住滿5年（有例外）；**直接持經商長期簽證的人可按規轉經商長期居留，不需先住滿5年**。此規則不同於申請永居的5年年資。
- 生效日：本輪確認官方制度當前有效，歷史法條確切施行／過渡日期尚未核對。
