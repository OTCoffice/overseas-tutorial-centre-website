How to use

  • Open app/index.html in Chrome, Safari or Edge.
  • Start with the A1 placement quiz. A2 unlocks only after A1 completion and sufficient accuracy.
  • Use Vocabulary and Speaking Interview practice before the mock flow.
  • Use Teacher mode to prepare a session summary or parent update.
