OTC Global Guide / 全球出國指南

Destination and route summaries: existing OTC content/country-study-destinations.json and content/work-travel-destinations.json plus existing OTC immigration country pages.
Compiled 2026-11-27. Compilation is not a new verification of all immigration policies. Official source links are retained per route. Generic preparation steps are not official application checklists.
Personal notes, favorites and progress remain in the browser's localStorage. JSON export/import is available. No account or cloud synchronization is provided.
Geographic data: Natural Earth, public domain, distributed via world-atlas 2.0.2 (ISC build license). Map boundaries are illustrative, not a statement about legal status.
https://github.com/topojson/world-atlas
D3 7.9.0 (ISC): https://d3js.org/
TopoJSON client 3.1.0 (ISC): https://github.com/topojson/topojson-client
License texts are bundled in vendor/.
UI and application code are independently implemented for OTC. No code, country guide text, brand, or account system from the reference website has been copied.
