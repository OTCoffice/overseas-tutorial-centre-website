Fee Explanation

收費說明

OTC 代辦本身免費，不設隱藏收費；費用通常由課程、住宿、活動、接送和保險構成，城市間差異較大。

Standard Process

標準流程

  1. 判斷家庭要的是英語沉浸還是學校觀察
  2. 看 Auckland / Wellington / Christchurch 等城市偏好
  3. 核對住宿、監護和短期健康材料
  4. 按合作路線匹配項目與可報名時段
