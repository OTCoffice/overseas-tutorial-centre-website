Cooperation memorandum

OTC 澳洲 VET / TAFE 擴展業務與海南、西安、成都、昆明、南寧等地機構合作備忘錄

擬面向海南、西安、成都、昆明、南寧等地教育國際合作、就業實習、職業教育、學生發展及技能出海相關機構，建立以澳洲 VET/TAFE 職業教育與合規移民導向資訊服務為核心的招生與服務合作模型。

合作背景

OTC 是一家英國註冊的教育支持與國際學習服務機構，長期服務中國及海外華語家庭，主要工作包括國際升學路線規劃、學術支持、文件整理、課程銜接、家長溝通、學生監督學習與跨境教育資源協調。

澳洲 VET / TAFE、護理健康、社區服務、康養、幼教與職業實習方向重新成為中國家庭關注的技能出海路線。海南、西安、成都、昆明、南寧在國際教育合作、職教出海、青年就業與區域開放方面具有獨特位置。

核心定位

OTC 希望將澳洲擴展業務重點放在「澳洲 VET / TAFE 職業教育、技能培養、就業實習能力準備及合規移民導向資訊服務」上。

合作模式不是承諾移民結果，而是幫助學生在早期看懂教育制度、職業方向、英語要求、placement、註冊、技能評估與簽證資訊之間的邏輯關係。

OTC 現有能力

  • 英國教育服務、國際升學與家長溝通經驗。
  • OTHM approved centre 相關經驗和資格課程運作能力。
  • 國際教育平台型學生轉介與 provider policy 跟蹤經驗。
  • 澳洲 provider / TAFE / VET agent application 管線整理。

澳洲拓展基礎

  • 澳洲政府學校、TAFE、VET 與 pathway provider application / EOI 管線已啟動。
  • 澳洲州級公共教育與學生支持資源已納入信息跟蹤。
  • 多類澳洲職業教育公開申請入口與合作流程已完成初步整理。
  • 健康護理、社區服務、VET/TAFE 中文內容建設中。

多地端價值

  • 補充澳洲職教、技能出海和就業實習方向產品。
  • 提升本地學生及家長服務黏性。
  • 形成多地本地國際教育合作示範案例。
  • 把本地職教需求轉化為可追蹤招生與服務數據。

目標學生與多地端切入口

學生類型

  • 中高職、高職、應屆畢業生及希望轉換職業方向的青年。
  • 對護理、康養、幼教、社區服務、酒店旅遊、IT、商科感興趣的學生。
  • 希望先用職業教育和英語能力打基礎，再理解後續海外可能路線的家庭。

多地合作入口

  • 職業院校 / 高職 / 中職國際合作部門。
  • 就業實習平台、青年職涯發展項目、康養幼教相關培訓機構。
  • 服務高中畢業生、職校畢業生和家長群體的升學服務入口。

OTC 交付資料

  • 澳洲 VET/TAFE 職業方向資料卡與中文路線手冊。
  • 學生意向表、route screening 表、家長 FAQ 與合規提示。
  • 講座 PPT、短課提綱、跟進郵件和可匿名化案例模板。

合作方向

VET / TAFE 職教與技能出海

共同設計面向海南、西安、成都、昆明、南寧學生的澳洲職業教育服務包：TAFE / VET、健康護理、aged care、community services、early childhood、business、IT、hospitality 等方向解讀，並提供英語、學術、職業能力和文件準備支持。

就業實習與職涯準備

共同開發澳洲職業方向介紹、英文 CV、面試、職場溝通、clinical / care communication、placement readiness 和國際實習資訊整理，在合規邊界內提供職涯導向服務。

共同建立招生與服務閉環

海南、西安、成都、昆明、南寧等地機構負責學生觸達、初步意向收集、線下信任建立和本地家長溝通。
OTC 提供澳洲 VET/TAFE 職業路線設計、provider 信息、文件清單、英語/學術/職業能力準備與雙語家長溝通。
合適學生按合規路徑進入平台轉介或 direct provider application；涉及簽證、移民、技能評估個案判斷時，轉介註冊專業人士。
學生在申請、入學前、入學後由雙方分工支持，形成案例、內容、家長口碑和後續招生渠道。

三階段合作模式

第一階段：信息互通與試點（1-2 個月）

Dawn Yun 老師協助介紹海南、西安、成都、昆明、南寧等地合適機構；OTC 提供公司簡介、澳洲方向服務說明、合規聲明和案例型材料；雙方選定 1-2 個試點方向。

第二階段：共建內容與招生活動（2-4 個月）

聯合舉辦澳洲 VET/TAFE 職業路線說明會，建立學生意向登記表，由 OTC 做初步 route screening。

第三階段：申請轉化與案例沉澱（4-6 個月）

對合適學生進行 provider application 支持，記錄需求、進度和問題類型，建立匿名案例庫並反哺澳洲 provider agent application。

優先產品包

  • 多地學生澳洲 VET / TAFE 職業路線說明會。
  • Aged care / community services / early childhood 中文路線手冊。
  • 英語 + 職業能力 + overseas study readiness 短課。
  • 學生 route screening 表與家長溝通模板。
  • 澳洲職業教育與合規移民資訊邊界講座。
  • 多地本地職教機構國際合作試點方案。

合規邊界

  • 不宣稱任何澳洲院校、政府部門或教育集團已正式授權，除非有書面 appointment / agreement。
  • 不承諾澳洲簽證結果、移民結果、工作結果或收入結果。
  • 可以提供公開、一般性的澳洲職業教育與移民相關資訊解讀，但不得對個別學生作簽證策略、移民資格或成功率判斷。
  • 涉及簽證、移民、法律或技能評估個案時，轉介註冊移民代理或合資格專業人士。

給 Dawn Yun 老師的轉介話術

Dawn 老師您好，OTC 目前正在系統化拓展澳洲方向教育服務，現階段重點放在澳洲 VET/TAFE 職業教育、健康護理、aged care、community services、early childhood、職業能力準備及合規移民導向資訊服務。

我們希望探索是否能與海南、西安、成都、昆明、南寧等地教育國際合作、職業教育、就業實習或學生發展相關機構建立合作，先從澳洲 VET/TAFE 職業路線說明、學生意向收集、家長溝通、英語與職業能力準備和試點案例開始。

90 天試點成果與評估指標

招生與觸達

  • 完成 2 場多地學生 / 家長路線說明會。
  • 收集 30-50 份澳洲 VET/TAFE 意向表。
  • 形成 10-15 個可初步 route screening 的學生檔案。

服務與轉化

  • 完成 3-5 個可跟進申請案例。
  • 建立學生文件清單、英語準備和職業方向跟進表。
  • 區分平台轉介、直接 provider application 和專業服務轉介。

證據與復盤

  • 輸出一份多地試點復盤報告。
  • 沉澱匿名案例、常見問題、家長關注點與內容選題。
  • 為後續澳洲 provider application 提供 market plan 和 recruitment pipeline 證據。

建議下一步

請 Dawn Yun 老師協助判斷海南、西安、成都、昆明、南寧各地最適合先接觸的 1-2 類機構：職業院校 / 高職 / 中職、國際教育合作辦公室、就業實習平台、護理康養幼教或旅遊酒店相關培訓機構。OTC 可先準備一場「多地學生如何理解澳洲 VET/TAFE 職業教育與職業相關移民導向路線」線上試講。
