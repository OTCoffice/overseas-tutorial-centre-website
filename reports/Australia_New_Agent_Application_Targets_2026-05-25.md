# Australia New Agent Application Targets

**Date:** 2026-05-25  
**Purpose:** Public-web scan for Australian education providers and school systems that publish a pathway for new education agent / representative applications.  
**Use:** Internal OTC Australia business-development target list. Verify each provider's current page before submission.

## Executive Summary

The best immediate targets are providers whose official pages clearly invite new agent applications, Expressions of Interest or representative enquiries. For OTC, the most realistic first wave should combine:

1. government-school systems with public application routes;
2. TAFE / public vocational providers;
3. private VET / ELICOS / pathway colleges with active agent recruitment pages;
4. universities that run EOI forms, but with a more selective approach.

Do not publicly call any provider a partner, representative relationship or appointed-agent relationship until written approval / signed agreement is received.

## Submission Package Template

Use a standard pack for all first-wave applications:

- OTC corporate profile and UK company registration details.
- UKPRN / OTHM approved-centre evidence.
- Australia office / representative-office evidence, if relevant.
- Compliance statement: ESOS, National Code, no false partnership claims, no migration/legal advice unless referred to registered professionals.
- Student-support statement: family communication, document organisation, route screening, welfare signposting, bilingual support.
- Market plan: China / Chinese-speaking families, UK-Australia progression, online supervised learning, VET/TAFE/health/community-care pathway interest.
- Referee explanation if provider requests existing Australian institution references and OTC cannot truthfully provide them yet.

## Safe Public Wording

Use:

> OTC is building a compliant Australia provider-contact and application pipeline across government schools, TAFE, private VET/ELICOS and selected universities.

Do not use:

> OTC is partnered with / appointed by / authorised by these providers.
