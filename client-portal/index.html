Client Access

OTC Client Portal

Three private-facing entrances for families, students and agent partners to review planning documents, case checklists and next-step notes.

Portal Map

Different users need different views.

Parents need fee scope, planning documents and case progress. Students need learning tasks and document checklists. Agent partners need referral notes, eligibility screening and communication records.

01 Parent Portal 家長端口

View pathway proposals, service scope, fee notes, document requests and application progress.

Open parent access 02 Student Portal 學生端口

Review learning tasks, English-readiness plans, assignment support notes and submission checklists.

Open student access 03 Agent Portal 代辦端口

Coordinate referrals, case screening, document gaps, commission notes and adviser communication.

Open agent access
This first portal layer is a lightweight client-access interface for proposal viewing and case coordination. For long-term use, sensitive passports, transcripts and financial evidence should move through production authentication and agreed secure channels.
