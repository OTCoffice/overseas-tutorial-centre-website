# Chapter 30

## Final Editorial Roadmap：從擴寫稿到可出版稿

### 30.1 現在這份稿件是什麼

目前這份稿件已不再是骨架，但仍不是最終出版稿。它更準確的名稱是 expanded internal review draft。它已包含路線圖、考試語言、clinical judgment、案例卷、題庫藍圖、督導指南和 RN reviewer checklist。但醫護教輔要公開銷售前，仍需完成臨床審核、合規核查、版式整理、題庫審核和讀者測試。

### 30.2 下一輪內容擴寫方向

如果繼續擴寫，優先順序如下：

1. 每章增加 5-10 道 mini drills。
2. 增加 20 個 NGN long cases。
3. 增加 medication risk card library。
4. 增加 maternal-child safety cue library。
5. 增加 mental health communication response bank。
6. 增加 bilingual glossary 到 200-300 terms。
7. 增加 tutor slide outline。

### 30.3 下一輪審核方向

內容審核應優先於美化：

- 核對 NCSBN / NCLEX administrative numbers。
- 核對 Ahpra/NMBA Stream B wording。
- RN review 高風險題。
- 刪除任何可能被理解為保證結果的語句。
- 檢查所有 per protocol / provider guidance 使用是否合適。
- 檢查中文是否過度簡化臨床行動。

### 30.4 版式方向

正式 PDF 不應只把 HTML 轉成長頁。建議：

- 每章開頭有 learning outcomes。
- 每章末尾有 review checklist。
- 案例題用灰底框。
- Key cue 用醒目標記。
- Wrong tags 用固定小標籤。
- Tables 保持可打印。
- Workbook pages 留空白填寫。

### 30.5 App 整合方向

App 下一步可做：

- 從題目 ID 連到書本章節。
- learner report 顯示「建議回讀章節」。
- 錯題關聯 glossary 保留。
- 題庫按 reviewer_status 控制公開。
- supervisor export 只輸出必要資料。

### 30.6 出版分階段

Phase 1: Internal expanded manuscript.

Phase 2: RN review sample and high-risk queue.

Phase 3: Public preview chapter + demo app.

Phase 4: Beta cohort with supervised learners.

Phase 5: Revised public PDF / ebook.

Phase 6: App-enhanced study pack.

### 30.7 成功標準

不是「字數很多」就成功。成功標準應是：

- 學員能更準確辨識 key cue。
- 學員能說出自己錯因。
- 學員能把錯題轉成下一步學習。
- RN reviewer 不發現重大安全錯誤。
- 對外文案不誤導。
- App 與書本互相支持。

### 30.8 本書的核心承諾

本書不承諾通過 NCLEX-RN，不承諾 AHPRA/NMBA 註冊，不承諾 OSCE 通過，也不承諾移民結果。它能承諾的是一套更清楚的學習方法：用中文建立理解，用英文保留考試語言，用錯題標籤診斷弱點，用案例拆解訓練 clinical judgment，用督導和審核保護安全。

### 30.9 給編輯的最後提醒

不要為了讓產品看起來更強，而刪掉 disclaimers。不要為了讓文章更吸引人，而寫保證性標題。不要為了增加題量，而降低審核標準。這個項目的長期價值在於可信，而不是誇張。

### 30.10 Closing Note

對很多華語護理師來說，NCLEX-RN 不是單一考試，而是一段把既有臨床經驗翻譯成另一套語言和監管框架的過程。這本書要做的，是在這段翻譯中提供一個清楚、穩定、可復盤的工作台。
