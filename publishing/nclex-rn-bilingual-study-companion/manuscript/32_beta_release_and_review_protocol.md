# Beta Release and Review Protocol

## 500-Page Working Edition Status

This edition is a beta review manuscript, not a final sale edition. It has been expanded into a large working manuscript for internal editorial review, RN / nursing educator review, bilingual clarity review and app-content alignment.

本版為「500 頁工作稿 / Beta 審稿版」，不是最終正式銷售版。它的用途是讓海外督導、海外書局、RN reviewer、雙語編輯與 App 產品審核人員在同一份材料上工作：看章節結構、臨床風險、雙語術語、錯題方法、App 題池與公開發布邊界是否一致。

Readers who receive this edition should understand three boundaries:

- It is an independent educational draft.
- It is not an official NCLEX, NCSBN, Pearson VUE, Ahpra, NMBA, ANMAC, Australian Government or migration-authority document.
- It does not guarantee exam pass, registration, employment, visa, course admission or any regulated outcome.

收到本版的讀者應清楚理解三個邊界：

- 本書是獨立教育工作稿。
- 本書不是 NCLEX、NCSBN、Pearson VUE、AHPRA、NMBA、ANMAC、澳洲政府或任何移民/監管機構的官方文件。
- 本書不承諾考試通過、不承諾註冊、不承諾就業、不承諾簽證、不承諾課程錄取，也不承諾任何受監管結果。

## Required Review Before Sale

Before the manuscript is sold as a finished book, the following review trail should be completed and archived.

1. Clinical review by an RN or nursing educator.
2. Source review for NCLEX, NCSBN, Ahpra/NMBA and Pearson VUE process statements.
3. Bilingual editorial review for Chinese explanation, English terminology and reader comprehension.
4. Compliance review for trademark language, no-guarantee wording and official-source boundaries.
5. App-content alignment review to ensure the book, trainer app, public demo and question banks use consistent risk labels.

正式銷售前，至少需要完成以下審核並保存記錄：

1. RN 或護理教育者臨床審核。
2. NCLEX、NCSBN、AHPRA/NMBA、Pearson VUE 流程與官方來源核對。
3. 中英雙語編輯審核，尤其是中文解析是否清楚、英文術語是否保留正確。
4. 合規審核，包括商標、非官方聲明、無保證聲明與官方來源邊界。
5. App 內容一致性審核，確認書稿、trainer app、公開 demo、題庫風險標籤一致。

## Beta Reader Feedback Form

Beta readers should answer these questions after reading sample chapters or using the trainer app:

1. Which chapter or app function helped you most?
2. Which Chinese explanation was still hard to understand?
3. Which English nursing terms need more examples?
4. Did any statement sound like a guarantee or official instruction?
5. Did any clinical explanation feel unsafe, outdated or too simplified?
6. Would you prefer a shorter workbook, a full reference book, or a book + app bundle?
7. What would make this useful enough for paid use?

試讀者中文回饋題：

1. 哪一章或哪個 App 功能最有幫助？
2. 哪些中文說明仍然難懂？
3. 哪些英文護理術語需要更多例子？
4. 是否有任何句子聽起來像保證通過或官方指令？
5. 是否有任何臨床說明讓你覺得不安全、過時或過度簡化？
6. 你更需要短版 workbook、完整參考書，還是書 + App 套裝？
7. 什麼改進會讓你願意付費使用？

## Current Editorial Decision

The current decision is:

**Go to controlled beta review. Do not sell as final edition yet.**

理由如下：

- 體量已足夠支撐大型書稿與產品展示。
- 雙語學習方法、錯題分類、App 連動與審稿索引已形成完整產品骨架。
- 高風險臨床內容仍需要 RN / nursing educator 審核。
- 470 個 page units 中仍有結構性重複，適合作為工作稿，但正式出版前需要進一步案例多樣化與語言潤色。
- 公開端應先發布「預覽 / Beta 審稿 / Demo 可用」，不應宣稱正式上市或保證效果。
