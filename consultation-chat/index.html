請提供目前學歷、目標國家或服務、計畫時間、主要困難與大約預算。系統會先整理方向與所需文件，再決定是否需要人工諮詢。

OTC Free Application Flow

免費代辦申請流程

先做需求匹配，再按院校官方要求準備及提交；服務本身不等於錄取或簽證保證。

01提交基本資料

提供學歷、成績單、英文程度、目標國家／專業、預算及申請時間。

02需求匹配

按學術背景、課程要求、城市、住宿及時間整理院校選項。

03官方要求核對

核對入學條件、文件、截止日期、費用及重修／轉學要求。

04申請協調

協助整理文件、填寫資料及按院校指定渠道提交。

05結果跟進

協助理解 offer、補件及下一步安排，院校收費按官方確認。

06佣金安排

如院校設有正式 agent commission，按書面合作政策處理，不收隱藏代辦費。
