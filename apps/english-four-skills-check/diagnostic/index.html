海外督導 OTC · 後續診斷程序

系統診斷工作台

收到學生原始報告後，使用現有 ChatGPT 工作階段完成初評及複核，再由本頁檢查格式、對照引文並輸出診斷書。這不是網站無人值守自動生成服務。

檔案只在本頁記憶體處理，不會自動上傳。下載的初評／複核工作單含作答原文；交給 ChatGPT 前請確認學生授權與必要資料範圍。本版本分析寫作及聽讀摘要；口說須另處理音檔，目前不評發音或流暢度。

查看完整虛構報告樣本 · 返回學生 App

1. 收取原始 JSON

在學生 App「我的報告」下載 JSON。不要上傳護照等身分文件。

把工作單交給 ChatGPT，取得初評 JSON 檔。也可把學生資料交到目前 OTC 工作對話，由助手完成後續程序。

2. 初評與複核

將複核工作單交給 ChatGPT，再取得包含 report 與 changes 的複核 JSON。程序會檢查每項回饋引用是否出現在原稿。

3. 匯出診斷書

打開 HTML，可用瀏覽器「列印 → 另存 PDF」。原始證據、資料缺口與實際複核紀錄均保留；不製造教師簽名。
